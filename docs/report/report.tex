\begin{abstract}
We present a hypernetwork system that generates complete neural network weights from prototype images in a single forward pass. Given a novel classification task described by a few example images per class, the system produces all parameters of a target classifier without any gradient-based optimisation at inference time.

We investigate two generation paradigms at different scales. A \textbf{direct generator} (50K target parameters) maps prototype embeddings to the full weight vector via an MLP, achieving 90.3\% zero-shot accuracy on EMNIST class combinations never seen during training. A \textbf{SANE-based generator} (109K target parameters) introduces per-neuron weight tokenisation and a Transformer autoencoder to compress the weight space, enabling generation at scales where direct methods fail.

The central finding is that generated initialisations converge to \textbf{statistically superior local minima} compared to standard initialisation methods (Random, Xavier, Kaiming He) after 3000 gradient descent steps. At 50K parameters, the effect is $+0.68$pp ($p < 10^{-6}$, 43/50 task wins). At 109K parameters with SANE tokenisation, the effect persists across all novelty levels, including tasks where all three classes are completely unseen ($+0.41$pp, $p = 0.00006$, 38/50 wins). Functional loss --- training by executing the generated weights on task data and backpropagating the classification error --- is the critical enabler: replacing it with MSE collapses autoencoder reconstruction accuracy from 97\% to 33\% and eliminates the better-minimum effect entirely.
\end{abstract}

\section{Introduction}
\label{sec:intro}

When a new classification task arises --- for example, distinguishing three species of butterfly from a few example photographs --- the standard approach is to train a neural network from scratch or fine-tune a pre-trained model. Both require iterative gradient-based optimisation, which is computationally expensive and requires careful hyperparameter selection. We ask a different question: \emph{can we learn a function that directly maps a task description to the weights of a network that solves it?}

Formally, we seek a meta-model $M$ such that
\begin{equation}
    W = M(\text{proto}(X_1), \text{proto}(X_2), \text{proto}(X_3))
\end{equation}
where $X_i$ are example images for each of the three classes, $\text{proto}(\cdot)$ is a learned prototype encoder that summarises a set of images into a fixed-size vector, and $W \in \mathbb{R}^d$ is the complete weight vector of a target classifier. At inference, this requires only a single forward pass through $M$ --- no gradient computation, no access to training data, no iterative optimisation.

This formulation is related to but distinct from several lines of prior work. \textbf{Model-Agnostic Meta-Learning} (MAML) \cite{finn2017model} learns a single shared initialisation optimised for fast adaptation; our approach generates a \emph{different, task-specific} initialisation for each task. \textbf{Prototypical Networks} \cite{snell2017prototypical} classify by distance to prototype embeddings but do not produce standalone models. \textbf{HyperNetworks} \cite{ha2016hypernetworks} generate weights for a target network but were originally applied to weight sharing within a single task, not cross-task generalisation. \textbf{SANE} \cite{schurholt2024towards} introduced per-neuron tokenisation and Transformer-based weight autoencoders for scalable weight space learning, which we build upon for our larger-scale experiments.

Our contributions are: (1) demonstrating that functional loss (training by executing generated weights) is critical for producing initialisations that converge to better minima; (2) showing that a cross-attention prototype encoder improves zero-shot accuracy by modelling inter-class relationships; (3) proving the better-minimum effect holds at 109K parameters using SANE tokenisation and functional autoencoder training; and (4) characterising how the effect scales with target network size and task novelty.

\section{Problem Setup}
\label{sec:setup}

\subsection{Dataset and Task Definition}

We use EMNIST ByClass \cite{cohen2017emnist}, which contains 62 character classes (digits 0--9, uppercase A--Z, lowercase a--z) as 28$\times$28 grayscale images. Each \textbf{task} is a 3-way classification problem over a randomly selected subset of three classes from this pool. This yields $\binom{62}{3} = 37{,}820$ possible tasks, of which we use a small fraction for training.

\subsection{Train/Test Split by Class}

To test genuine generalisation, we partition classes (not tasks) into two groups:
\begin{itemize}[noitemsep]
    \item \textbf{Seen classes} (0--49): Digits 0--9, uppercase A--Z, and lowercase a--n. Used during hypernetwork training. Tasks are sampled from $\binom{50}{3} = 19{,}600$ possible combinations.
    \item \textbf{Unseen classes} (50--61): Lowercase \textbf{o, p, q, r, s, t, u, v, w, x, y, z}. These 12 characters never appear during training in any form. At evaluation, we construct tasks containing 0, 1, 2, or 3 unseen classes to measure generalisation at increasing levels of novelty.
\end{itemize}

This design ensures that the most challenging evaluation (3/3 unseen) tests the system on character classes it has \emph{literally never encountered} --- not merely novel combinations of familiar classes. Note that some unseen lowercase letters have uppercase counterparts in the seen set (e.g., lowercase `o' is unseen while uppercase `O' is seen), though the visual forms differ substantially in handwriting.

\subsection{Model Zoo}

We first train a collection of conventionally-trained target classifiers (the ``model zoo''). For each training task, a target MLP is trained with Adam (lr $= 10^{-3}$, 30 epochs) to convergence, typically achieving $>$98\% test accuracy. The zoo provides $(task, weights)$ supervision pairs for training the hypernetwork. We experiment with zoo sizes of 200 and 500 tasks to investigate the effect of task diversity.

\paragraph{Problem Space Coverage.} The training zoo samples a very small fraction of the total problem space. With 50 seen classes, there are $\binom{50}{3} = 19{,}600$ possible 3-class tasks. Our training sets cover:
\begin{itemize}[noitemsep]
    \item \textbf{200 tasks}: 1.02\% of the seen-class problem space (0.53\% of the full 37,820-task space)
    \item \textbf{500 tasks}: 2.55\% of the seen-class problem space (1.32\% of the full space)
\end{itemize}
The fact that the hypernetwork achieves 90.3\% zero-shot accuracy on unseen classes from just 2.55\% coverage of the seen-class task space suggests that it has learned highly generalisable structure about the relationship between visual prototypes and classifier weights, rather than memorising individual task solutions.

\subsection{Evaluation Protocol}

For each evaluation task, we:
\begin{enumerate}[noitemsep]
    \item Sample 20 prototype images per class from the EMNIST training split.
    \item Generate weights $W = M(\text{proto}(X_1), \text{proto}(X_2), \text{proto}(X_3))$ in a single forward pass.
    \item Measure \textbf{zero-shot accuracy}: classification accuracy of the generated weights on the EMNIST test split, with no fine-tuning.
    \item Optionally \textbf{fine-tune} the generated weights with $k$ SGD steps (lr $= 0.01$) on fresh training data, and compare to Kaiming-initialised weights fine-tuned with the same budget.
    \item Report the \textbf{accuracy gap} (generated minus Kaiming) and a \textbf{paired Wilcoxon signed-rank test} across 50 evaluation tasks.
\end{enumerate}

\section{Method}
\label{sec:method}

\subsection{Prototype Encoding}

Each class in a task is described by $K = 20$ example images. We investigate two encoding strategies:

\paragraph{Mean-Pool Encoder.} A shared MLP encoder $\phi: \mathbb{R}^{784} \to \mathbb{R}^{128}$ maps each image to an embedding, and the class prototype is the mean:
\begin{equation}
    p_c = \frac{1}{K} \sum_{k=1}^{K} \phi(x_{c,k}) \in \mathbb{R}^{128}
\end{equation}
The task embedding is the concatenation of the three class prototypes: $z_{\text{task}} = [p_1; p_2; p_3] \in \mathbb{R}^{384}$.

\paragraph{Cross-Attention Encoder.} After computing the three class prototypes via mean-pooling, we apply multi-head self-attention across the three prototypes:
\begin{equation}
    [\hat{p}_1; \hat{p}_2; \hat{p}_3] = \text{LayerNorm}([p_1; p_2; p_3] + \text{MultiHeadAttn}([p_1; p_2; p_3]))
\end{equation}
This allows the encoder to model \emph{inter-class relationships} --- for example, that two of the three classes are visually similar and the third is distinct, which affects how the classifier's decision boundaries should be structured.

\subsection{Approach A: Direct Generation (50K Parameters)}

For target networks with up to $\sim$50K parameters, we use a direct MLP generator:
\begin{equation}
    W = G(z_{\text{task}}) = f_3(\text{ReLU}(f_2(\text{ReLU}(f_1(z_{\text{task}})))))
\end{equation}
where $f_1: \mathbb{R}^{384} \to \mathbb{R}^{512}$, $f_2: \mathbb{R}^{512} \to \mathbb{R}^{512}$, $f_3: \mathbb{R}^{512} \to \mathbb{R}^{d}$, and $d$ is the total number of parameters in the target network. The target architecture is a single-hidden-layer MLP ($784 \to 64 \to 3$, $d = 50{,}435$).

\subsection{Approach B: SANE-Based Generation (109K+ Parameters)}

Direct generation fails for larger targets ($d > 50$K) because the generator's hidden layers cannot coordinate enough output dimensions simultaneously --- the loss landscape around random generated weights is a flat plateau at chance-level cross-entropy.

We overcome this using \textbf{SANE tokenisation} \cite{schurholt2024towards}: instead of treating the weight vector as a monolithic $d$-dimensional vector, we decompose it into per-neuron tokens. For a target MLP with layers of width $[n_1, n_2, \ldots, n_L]$, each neuron $j$ in layer $\ell$ contributes one token:
\begin{equation}
    t_{\ell,j} = [w_{\ell,j,1}, \ldots, w_{\ell,j,n_{\ell-1}}, b_{\ell,j}] \in \mathbb{R}^{n_{\ell-1}+1}
\end{equation}
containing the neuron's incoming weights and bias. All tokens are zero-padded to a common size $d_t = \max_\ell(n_{\ell-1} + 1)$.

A \textbf{Transformer autoencoder} processes this token sequence:
\begin{align}
    z_{\ell,j} &= \text{Encoder}(t_{\ell,j}, \text{pos}(\ell, j)) \in \mathbb{R}^{d_z} \\
    \hat{t}_{\ell,j} &= \text{Decoder}(z_{\ell,j}, \text{pos}(\ell, j))
\end{align}
where $\text{pos}(\ell, j)$ is a learned 2D positional embedding encoding the layer index and neuron index. The encoder and decoder are 4-layer Transformer encoders with $d_{\text{model}} = 256$, 8 heads, and latent dimension $d_z = 32$ per token.

For a target MLP $784 \to 128 \to 64 \to 3$, this produces $128 + 64 + 3 = 195$ tokens with a total latent dimensionality of $195 \times 32 = 6{,}240$ --- a 17$\times$ compression from the 108,931-dimensional weight vector.

A \textbf{latent hypernetwork} then maps prototype embeddings to this latent space:
\begin{equation}
    \hat{z} = H(z_{\text{task}}) \in \mathbb{R}^{N_{\text{tokens}} \times d_z}
\end{equation}
and the frozen decoder reconstructs the full weight vector from $\hat{z}$.

\subsection{Functional Loss}
\label{sec:functional_loss}

The core innovation is \textbf{functional loss}: rather than regressing to reference weight values (MSE), we evaluate the generated weights by \emph{executing} them as a neural network on task-specific data:
\begin{equation}
    \mathcal{L}_{\text{func}} = \text{CrossEntropy}\!\left(f(X_{\text{eval}}; W_{\text{gen}}),\; y_{\text{eval}}\right)
\end{equation}
where $f(\cdot\,; W_{\text{gen}})$ denotes the forward pass of the target network parameterised by the generated weights $W_{\text{gen}}$, and $(X_{\text{eval}}, y_{\text{eval}})$ are images and labels sampled from the task's data.

Crucially, this forward pass is implemented as raw tensor operations (matrix multiplications using slices of the weight vector), not via \texttt{load\_state\_dict}, making the entire pipeline differentiable. Gradients flow from the classification loss through the target network's computations, through the weight values, and back into the generator (and for SANE, through the decoder).

The full training objective combines functional and MSE loss:
\begin{equation}
    \mathcal{L} = \mathcal{L}_{\text{func}} + \lambda \cdot \mathcal{L}_{\text{MSE}}
\end{equation}
with $\lambda = 0.1$. The MSE term provides early-training stability by nudging generated weights toward the zoo reference.

\subsection{Training Pipeline}

\paragraph{Direct (50K):} Single-stage training with functional loss, Adam optimiser (lr $= 5 \times 10^{-4}$), cosine annealing, batch size 8, up to 300 epochs with patience 60.

\paragraph{SANE (109K):} Three-stage pipeline:
\begin{enumerate}[noitemsep]
    \item \textbf{Functional Autoencoder} (500 epochs): Train encoder + decoder on weight reconstruction. MSE-only for epochs 1--50 (warm-up), then linearly ramp functional loss from epoch 50--100, full functional loss thereafter.
    \item \textbf{Latent Hypernetwork} (200 epochs): Train MLP to predict latent codes from prototype embeddings. Decoder frozen. Loss: functional + latent MSE.
    \item \textbf{End-to-End} (150 epochs): Unfreeze decoder, fine-tune entire pipeline with functional loss. Differential learning rates: $5 \times 10^{-5}$ for SANE, $2 \times 10^{-4}$ for hypernetwork.
\end{enumerate}

\section{Discussion}
\label{sec:discussion}

\subsection{The Role of Functional Loss}

Functional loss is the single most important design decision in this work. It transforms the autoencoder's latent space from one that preserves weight \emph{values} (MSE, 33\% reconstruction accuracy) to one that preserves weight \emph{function} (97\% accuracy). This distinction is crucial because weight space has enormous redundancy: many different weight configurations implement the same function due to permutation symmetries, scale invariances, and flat directions in the loss landscape. MSE treats all weight differences equally; functional loss cares only about differences that affect predictions.

\subsection{What the Better-Minimum Effect Means}

The persistent accuracy advantage at convergence ($+0.41$--$0.68$pp after 3000 SGD steps, all $p < 0.001$) indicates that the generated weights do not merely converge faster but land in \emph{different, better basins of attraction} in the loss landscape. This is verified by the loss values at convergence: generated initialisations consistently achieve lower cross-entropy, not just higher accuracy.

This suggests the hypernetwork has learned something about the geometry of the loss landscape for visual classification tasks: it knows which regions of weight space contain the best solutions and can steer the initialisation toward them based on the visual structure of the task.

\subsection{Scaling Behaviour}

Direct generation encounters a hard barrier at $\sim$50K parameters due to a loss landscape plateau: randomly generated 100K+ weight vectors produce networks whose outputs are effectively uniform over classes, providing no gradient signal. SANE tokenisation resolves this by decomposing the problem into per-neuron tokens that a Transformer can process locally. The functional autoencoder ensures the compressed representation preserves the information needed for the better-minimum effect.

At 236K, the effect weakens for fully unseen tasks, likely because the latent space must represent a more complex weight manifold with the same capacity. Scaling the zoo size proportionally and applying the cross-attention + task diversity improvements to the SANE pipeline are immediate next steps.

\subsection{Limitations}

\begin{itemize}[noitemsep]
    \item The better-minimum effect, while statistically robust, is small at convergence ($+0.4$--$0.7$pp). The primary practical value is in the low-step regime ($+32$pp at 10 steps), relevant for compute-constrained or real-time deployment.
    \item All experiments use EMNIST (28$\times$28 grayscale characters). The ``unseen'' classes are still from the same visual domain. Testing on cross-domain tasks (e.g., training on characters, testing on natural images) would strengthen the generalisation claim.
    \item The target architectures are MLPs. Extending to CNNs and Transformers via SANE's natural per-channel tokenisation is straightforward in principle but untested.
    \item The 150-model zoo is small relative to the 109K--236K weight space dimensionality. Larger zoos would likely improve both zero-shot accuracy and the persistence of the better-minimum effect at scale.
\end{itemize}

\subsection{Future Work}

\begin{enumerate}[noitemsep]
    \item \textbf{Problem space coverage scaling law.} With 500 training tasks covering only 2.55\% of the seen-class problem space and already achieving 90.3\% zero-shot, a natural question is how zero-shot accuracy scales with coverage. Systematically varying the training set from 1\% to 50\% coverage and measuring the resulting zero-shot accuracy would characterise the sample efficiency of the approach and determine whether there are diminishing returns or phase transitions.
    \item \textbf{Apply cross-attention and task diversity to SANE pipeline.} The ablation study (Table~\ref{tab:ablations}) showed these improvements are additive at 50K but they have not yet been applied to the 109K SANE pipeline. Given that the 109K result already shows the better-minimum effect, combining it with the improved encoder and larger zoo could strengthen the effect and improve zero-shot accuracy.
    \item \textbf{CNN and Transformer target architectures.} SANE's per-neuron tokenisation naturally extends to per-channel tokenisation for convolutional layers. Testing on CNN targets (e.g., small ResNets) would demonstrate whether the approach generalises beyond fully-connected architectures.
    \item \textbf{Cross-domain generalisation.} All current experiments use EMNIST (grayscale characters). Testing whether a hypernetwork trained on character classification tasks can generate useful initialisations for natural image tasks (e.g., CIFAR-100 subsets) would test the limits of the learned structural priors.
    \item \textbf{Continual learning.} Investigating whether the better-minimum effect compounds across sequential tasks --- i.e., whether generated initialisations not only start better but also resist catastrophic forgetting better than standard initialisations.
\end{enumerate}

% ============================================================
\section{Conclusion}
\label{sec:conclusion}

We demonstrated that prototype-conditioned hypernetworks, trained with functional loss, generate neural network initialisations that converge to statistically superior local minima compared to all standard initialisation methods. The effect is verified with both SGD and Adam optimisers, across 220+ evaluation tasks, against Random, Xavier, and Kaiming baselines, at two target network scales (50K and 109K parameters), and on tasks involving character classes never seen during training.

The key insight is architectural: functional loss --- optimising for what the generated weights \emph{do} rather than what they \emph{look like} --- is necessary and sufficient for the better-minimum effect. Without it, autoencoder reconstruction and hypernetwork generation both fail to produce functionally useful weights. With it, even a simple MLP generator achieves 90.3\% zero-shot accuracy on completely novel classification tasks, and a SANE-based generator scales to 109K+ parameters while preserving the effect.
