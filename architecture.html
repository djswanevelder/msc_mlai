System Architecture

Two approaches to weight generation: direct (V4) and autoencoder-based (V4-AE)

1. Overview: The Two-Level Problem

The system operates at two levels. At the inner level, a small target classifier solves a 3-way classification task (e.g., distinguishing three character classes). At the outer level, a meta-model (hypernetwork) learns to produce the target classifier's weights from a description of the task.

3. Approach B: Autoencoder-Mediated Generation (V4-AE, 109K+ params)

To scale beyond 50K parameters, we introduce a weight autoencoder that compresses the target weight space to a small latent code. The hypernetwork generates in this latent space, and the decoder expands back to full weights. This decouples the hypernetwork's output dimension from the target size.

4. The Functional Loss — Key Innovation

Both approaches are trained with functional loss: instead of matching weight values (MSE), we measure whether the generated weights produce correct classifications. This is what makes the method work.

Figure 6. Functional loss. The forward pass through the target MLP is reimplemented as differentiable tensor operations (matrix multiplications using slices of the weight vector). This allows end-to-end gradient flow, directly optimising for classification accuracy rather than weight similarity.
Why MSE alone fails: Weight-space MSE treats all parameters equally. But a tiny perturbation to an output bias has vastly different functional effect than the same perturbation deep in the first layer. MSE can achieve low reconstruction error while completely destroying the network's function. Functional loss optimises what matters: does the generated network classify correctly?
